# Security and safety

This demonstration runs offline. It does not execute candidate-written code, contact any service, rewrite its own source, alter AI model weights, or make autonomous production decisions. It generates a bounded fixed-structure policy and local files.

SHA-256 digests detect accidental tampering, but their manifest is controlled by the same writer and is **not** cryptographically authenticated. Independent evaluation must use signed commits, controlled datasets, a separate custody system and independent reviewers.

Do not ingest sensitive or identifiable records without documented authorization, privacy review and a least-privilege sandbox. Please disclose vulnerabilities through a private GitHub security advisory when the repository exists; do not publish exploit details before remediation.
